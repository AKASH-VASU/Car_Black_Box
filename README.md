# 🚗 Car Black Box using PIC18F4580

### 📌 Description

A microcontroller-based **Car Black Box** developed using PIC18F4580 to monitor and record vehicle parameters and important events. The system provides real-time vehicle information through a CLCD.

### 🛠️ Technologies & Tools

* Embedded C
* PIC18F4580
* MPLAB X IDE
* XC8 Compiler
* CLCD
* ADC
* Timers
* Interrupts
* CAN Protocol

### ✨ Features

* 🚘 Vehicle parameter monitoring
* 📊 Real-time data display
* 📝 Event logging
* 📡 CAN-based communication
* ⚡ Interrupt-based event handling
* 📟 CLCD interfacing

### ⚙️ Working

* Vehicle parameters are collected through connected sensors/input sources.
* PIC18F4580 processes the received data.
* Important vehicle events are recorded in the system.
* Current vehicle information is displayed on the CLCD.
* CAN communication is used for exchanging vehicle data between nodes.
